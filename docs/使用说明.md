# MystiaAI 功能说明（使用者向）

本文介绍 MystiaAI 模组为玩家带来的全部功能，只描述你在游戏和配置工具中能看到、能用到的内容。

## 一、AI 实时对话

### 会替换的文本

- **白天地图闲聊**：白天在地图上找 NPC 对话，对方的台词由 AI 根据角色人设实时生成
- **营业闲聊气泡**：夜晚营业时，稀客和普通客人的闲聊气泡由 AI 生成
- **上菜后评价语**：客人吃完料理后的评价由 AI 生成，会结合吃的是什么菜、给出了什么等级的评价

### 保持原文的文本

- 剧情对话一律保持游戏原文，不会替换
- 羁绊升级时的对话保持原文
- 稀客的点餐文本保持原文

### 生成的特点

- 每次对话都重新生成，每次内容都不一样
- AI 知道当前的环境：游戏内时间、是否在营业中、你和这个角色的羁绊等级
- AI 有概率聊到当天《文文新闻》的内容（概率可以调，见配置部分）
- 语言自动跟随游戏内设置（简体中文/繁体中文/英语/日语/韩语）

## 二、与 NPC 自由对话

这是本模组最核心的玩法：你不只是看 NPC 说话，还能自己接话。

- NPC 说完话后，对话框区域会出现一个**输入框**，外观与原对话框融为一体
- 你可以**自由输入任何想说的话**，NPC 会承接你的话回应
- 也可以点击 **AI 推荐回复**：自动生成两条风格不同的候选台词（比如一条热情、一条吐槽），点一下就算你说出口
- 推荐回复不满意可以点「重新生成推荐回复」
- 点击输入框后开始打字，打字期间游戏快捷键自动屏蔽，不会误触；输入完点「完成」按钮送出
- 不想说话就直接按原方式继续对话，互不影响

## 三、角色人设系统

每个角色的说话方式由「人设」决定。

- 模组内置 **116 个角色的完整人设**：69 位稀客 + 47 位普通客人，包含角色档案、性格、口癖，以及他们在原作中的点餐/评价台词范本
- AI 生成时会优先模仿原作台词的句式与口吻，尽量不出戏、不用网络流行语
- 人设按中文角色名整理，你可以逐角色查看和修改（见配置部分）
- 如果某个角色没有专属人设，会依次向上回退：角色 → 所属分类（稀客/路边居民/普通客人）→ 全局默认

## 四、网页配置工具

配置不需要手写文件，打开网页工具选择 `文档/MystiaAI` 文件夹即可：

- 在线版：https://shrimp9527.github.io/MystiaAI/（推荐 Chrome / Edge，可直接保存回文件夹）
- 仓库根目录也有同功能的离线版 `MystiaAI配置工具.html`

### 通用设置页

- **启用 AI 文本替换**：总开关
- **普通客人也用 AI**：关闭后营业时间的普通客人保持原文（稀客不受影响）
- **AI 模型供应商**：下拉选择 DeepSeek（默认）/ OpenAI / GLM / 月之暗面 / Claude，切换后自动填入默认 API 地址与最新模型；选 Custom 可接本地模型（如 Ollama、LM Studio）
- **API Key**：你的密钥，本地模型可留空
- **最大字数**：AI 每句话的长度上限，默认 50 字
- **超时时间**：超过该秒数未生成完成则回退原文
- **流式显示**：开启后游戏内逐字实时显示生成过程（默认关，不稳定）
- **报纸话题频率**：滑块调节 AI 提及当日《文文新闻》的概率，0% 为完全不提，100% 为每次都提，默认 30%

### 角色设定页

- 左侧按分类列出全部角色（稀客/路边居民/普通客人），支持搜索
- 选中角色后右侧显示并可编辑其完整人设
- 可以新增自定义角色条目、删除条目、一键恢复默认人设
- 未填写人设的条目有明确标注，运行时按回退规则处理

### 生效方式

- 保存后游戏内 2 秒内自动热重载，不用重启游戏
- 配置文件也完全可以脱离工具手动编辑，就是三个普通 JSON 文件

## 不会影响内容
- 不影响剧情推进与结局
- 不影响存档，可随时卸载还原
- 不改变任何游戏机制（经营、菜谱、好感度数值等）
- 只在 AI 不可用时回退原文，绝不会让对话消失或卡死
